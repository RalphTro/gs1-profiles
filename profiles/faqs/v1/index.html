GS1 FAQ Resource Profile — v1

Profile identifier: https://ralphtro.github.io/gs1-profiles/profiles/faqs/v1

This profile describes the structure and semantics of FAQ resources referenced from a GS1-conformant Digital Link resolver via the gs1:faqs link type.

Constituent artefacts

Artefact Role Format
profile.jsonld PROF description application/ld+json
schema.json Validation (JSON) application/schema+json
shape.ttl Constraints (RDF/JSON-LD) text/turtle
example.jsonld Example instance application/ld+json

Usage in a linkset

{
  "href": "…/faqs.jsonld",
  "title": "FAQs",
  "type": "application/ld+json",
  "hreflang": ["en"],
  "context": ["https://ralphtro.github.io/gs1-profiles/profiles/faqs/v1"],
  "public": true,
  "@linkType": "https://ref.gs1.org/voc/faqs"
}
